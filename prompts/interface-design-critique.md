---
description: Critique an interface for craft quality, then rebuild the weak parts instead of only describing them.
---

Critique the current interface like a demanding design lead, then improve it.

Evaluation frame:
- Composition: hierarchy, focal point, density, rhythm, proportion
- Craft: spacing discipline, typography contrast, surface hierarchy, interaction states
- Content: coherence, realism, clarity of labels and data
- Structure: remove layout hacks when a simpler composition is available

Execution rules:
- Do the work after the critique. Do not stop at commentary.
- Preserve the product's existing visual language unless the task explicitly calls for a restyle.
- Prefer decisive structural improvements over cosmetic tweaks.
- Keep user-facing copy in Traditional Chinese if new copy is introduced.

Deliver:
- The improved implementation
- A short summary of what was rebuilt and why
