Design and implement interface work for an app, dashboard, or internal tool.

Before coding:
1. Read `skills/skill-interface-design/SKILL.md`.
2. Check for `.vscode/interface-design/system.md`.
3. If a system exists, follow it.
4. If no system exists, infer direction from the product context before building.

Design standard:
- Start from user intent, not generic dashboard defaults.
- Make deliberate choices for palette, depth, surfaces, typography, and density.
- Preserve the established product language when it already exists.
- Avoid marketing-site patterns unless the task explicitly asks for them.

After implementation:
- Summarize the direction in a few concrete points.
- Offer to save any new patterns into `.vscode/interface-design/system.md`.
