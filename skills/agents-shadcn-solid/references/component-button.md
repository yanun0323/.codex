# Button

Source: https://shadcn-solid.netlify.app/docs/components/button

## Import

```ts
import { Button } from "@/components/ui/button"
```

## Minimal usage

```tsx
<Button>Click me</Button>
```

## Notes

- Use `variant`/`size` props instead of custom class spam.
- Avoid raw `<button>` outside the UI layer.
