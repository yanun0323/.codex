### Install Core Accordion Dependency

Source: https://github.com/hngngn/shadcn-solid/blob/main/docs/src/data/docs/components/accordion.mdx

Install the core @kobalte/core package, which provides the underlying Accordion logic. This is required for both manual TailwindCSS and UnoCSS setups.

```bash
bun install @kobalte/core
```
