### Basic Alert Usage Example (SolidJS/TSX)

Source: https://github.com/hngngn/shadcn-solid/blob/main/docs/src/data/docs/components/alert.mdx

Demonstrates how to render a basic Alert component with a title, description, and an optional icon within a SolidJS application.

```tsx
<Alert>
  <TbTerminal class="h-4 w-4" />
  <AlertTitle>Heads up!</AlertTitle>
  <AlertDescription>
    You can not add components and dependencies to your app using the cli, yet.
  </AlertDescription>
</Alert>
```
