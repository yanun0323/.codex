### Use Shadcn Solid Button Component in JSX

Source: https://github.com/hngngn/shadcn-solid/blob/main/docs/src/data/docs/installation/manual.mdx

Demonstrates how to import the `Button` component from the project's UI library and render it within a SolidJS functional component, showing basic usage.

```JSX
import { Button } from "@/components/ui/button"

export default function Home() {
  return (
    <div>
      <Button>Click me</Button>
    </div>
  )
}
```
