### Basic Card Usage Example - TSX

Source: https://github.com/hngngn/shadcn-solid/blob/main/docs/src/data/docs/components/card.mdx

Demonstrates a basic example of how to use the Card component with its header, content, and footer sub-components in a Solid.js application.

```tsx
<Card>
  <CardHeader>
    <CardTitle>Card Title</CardTitle>
    <CardDescription>Card Description</CardDescription>
  </CardHeader>
  <CardContent>
    <p>Card Content</p>
  </CardContent>
  <CardFooter>
    <p>Card Footer</p>
  </CardFooter>
</Card>
```
