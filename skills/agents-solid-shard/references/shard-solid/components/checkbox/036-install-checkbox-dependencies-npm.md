### Install Checkbox Dependencies (NPM)

Source: https://github.com/hngngn/shadcn-solid/blob/main/docs/src/data/docs/components/checkbox.mdx

Manually install the required core dependency for the Checkbox component using npm. This step is necessary for both Tailwind CSS and UnoCSS setups.

```bash
bun install @kobalte/core
```
