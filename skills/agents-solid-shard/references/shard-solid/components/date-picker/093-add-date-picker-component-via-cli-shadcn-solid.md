### Add Date Picker Component via CLI (shadcn-solid)

Source: https://github.com/hngngn/shadcn-solid/blob/main/docs/src/data/docs/components/date-picker.mdx

Use the shadcn-solid CLI to automatically add the Date Picker component files and dependencies to your project. This is the recommended method for quick setup.

```bash
bunx shadcn-solid@latest add date-picker
```
