### Install Navigation Menu Component (Bash)

Source: https://github.com/hngngn/shadcn-solid/blob/main/docs/src/data/docs/components/navigation-menu.mdx

Installs the Navigation Menu component using the shadcn-solid CLI. This command adds the necessary files and dependencies for the component.

```bash
bunx shadcn-solid@latest add navigation-menu
```
