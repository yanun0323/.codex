### Add Radio Group Component using shadcn-solid CLI (Bash)

Source: https://github.com/hngngn/shadcn-solid/blob/main/docs/src/data/docs/components/radio-group.mdx

Installs the Radio Group component into your project using the shadcn-solid command-line interface.

```bash
bunx shadcn-solid@latest add radio-group
```
