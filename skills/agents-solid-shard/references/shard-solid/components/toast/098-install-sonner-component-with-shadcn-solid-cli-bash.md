### Install Sonner Component with shadcn-solid CLI (Bash)

Source: https://github.com/hngngn/shadcn-solid/blob/main/docs/src/data/docs/components/sonner.mdx

Use the shadcn-solid CLI to automatically add the Sonner toast component and its dependencies to your project.

```bash
bunx shadcn-solid@latest add sonner
```
