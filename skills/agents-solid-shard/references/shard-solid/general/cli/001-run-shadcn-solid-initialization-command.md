### Run shadcn-solid Initialization Command

Source: https://github.com/hngngn/shadcn-solid/blob/main/docs/src/data/docs/installation/solid-start.mdx

Execute the shadcn-solid initialization command via bunx. This command interactively guides the user through setting up the necessary configuration file (components.json) for the UI library, tailoring it to the project's setup.

```bash
bunx shadcn-solid@latest init
```
