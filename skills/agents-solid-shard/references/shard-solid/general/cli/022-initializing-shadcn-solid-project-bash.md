### Initializing shadcn-solid Project - Bash

Source: https://github.com/hngngn/shadcn-solid/blob/main/docs/src/data/docs/cli.mdx

Use this command to initialize the shadcn-solid configuration and install necessary dependencies in your project. It sets up `components.json`, adds utility functions, and configures Tailwind CSS. The command will prompt for configuration details.

```bash
bunx shadcn-solid@latest init
```
