### Add Shadcn Solid Component via CLI

Source: https://github.com/hngngn/shadcn-solid/blob/main/docs/src/data/docs/installation/manual.mdx

Executes the `bunx shadcn-solid@latest add` command to automatically add a specified component (e.g., `button`) to the project, including its dependencies and files.

```Bash
bunx shadcn-solid@latest add button
```
