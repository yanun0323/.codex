### Initialize shadcn-solid Project

Source: https://github.com/hngngn/shadcn-solid/blob/main/docs/src/data/docs/installation/astro.mdx

Run the shadcn-solid initialization command using pnpx to set up the project structure and configuration for shadcn-solid components.

```bash
pnpx shadcn-solid@latest init
```
