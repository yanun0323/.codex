### Initialize shadcn-solid CLI Configuration (Bash)

Source: https://github.com/hngngn/shadcn-solid/blob/main/docs/src/data/docs/components-json.mdx

Run this command in your project's root directory to create the initial `components.json` file, which is required for using the shadcn-solid CLI to add components.

```bash
bunx shadcn-solid@latest init
```
