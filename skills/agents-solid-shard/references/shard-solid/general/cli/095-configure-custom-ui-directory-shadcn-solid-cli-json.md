### Configure Custom UI Directory - shadcn-solid CLI - JSON

Source: https://github.com/hngngn/shadcn-solid/blob/main/docs/src/data/docs/changelog.mdx

This JSON configuration snippet shows how to customize the installation directory for UI components using the shadcn-solid CLI. The `aliases.ui` property specifies the desired path for the components.

```json
{
  "aliases": {
    "ui": "@/ui"
  }
}
```
