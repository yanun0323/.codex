### Add a Component using shadcn-solid CLI

Source: https://github.com/hngngn/shadcn-solid/blob/main/docs/src/data/docs/installation/solid-start.mdx

Use the shadcn-solid CLI's 'add' command to incorporate a specific UI component into the project. This command fetches the component's code and dependencies, placing them in the configured components directory, making them ready for use.

```bash
bunx shadcn-solid@latest add button
```
