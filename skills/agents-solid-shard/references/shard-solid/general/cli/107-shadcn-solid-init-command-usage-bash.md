### shadcn-solid init Command Usage - Bash

Source: https://github.com/hngngn/shadcn-solid/blob/main/docs/src/data/docs/cli.mdx

This shows the general usage syntax for the `shadcn-solid init` command, including available options. The `-c` option specifies the working directory, and `-h` displays help.

```bash
Usage: shadcn-solid init [options]

initialize and install dependencies

Options:
  -c, --cwd <path>  the working directory (default: "path\to\my-app")
  -h, --help        display help for command
```
