### Install Kobalte Core Dependency - Bash

Source: https://github.com/hngngn/shadcn-solid/blob/main/docs/src/data/docs/components/collapsible.mdx

Install the core Kobalte library, which provides the underlying logic for the Collapsible component. This is required for both Tailwind CSS and UnoCSS setups.

```bash
bun install @kobalte/core
```
