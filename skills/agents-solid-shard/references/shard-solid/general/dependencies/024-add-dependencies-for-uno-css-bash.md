### Add Dependencies for Uno CSS - Bash

Source: https://github.com/hngngn/shadcn-solid/blob/main/docs/src/data/docs/installation/manual.mdx

Install the required npm packages when using Uno CSS as your styling framework. These packages provide utilities for animations, class variations, and merging class names.

```bash
bun install unocss-preset-animations class-variance-authority clsx tailwind-merge
```
