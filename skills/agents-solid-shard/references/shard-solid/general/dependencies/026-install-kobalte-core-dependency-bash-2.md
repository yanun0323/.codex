### Install Kobalte Core Dependency (Bash)

Source: https://github.com/hngngn/shadcn-solid/blob/main/docs/src/data/docs/components/navigation-menu.mdx

Installs the core Kobalte library, which is a required dependency for the shadcn-solid Navigation Menu component.

```bash
bun install @kobalte/core
```
