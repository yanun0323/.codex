### Install Kobalte Core Dependency - Bash

Source: https://github.com/hngngn/shadcn-solid/blob/main/docs/src/data/docs/components/menubar.mdx

Installs the required @kobalte/core dependency using npm, which is a peer dependency for the shadcn-solid Menubar component.

```bash
bun install @kobalte/core
```
