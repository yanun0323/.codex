### Install Kobalte Core Dependency - Bash

Source: https://github.com/hngngn/shadcn-solid/blob/main/docs/src/data/docs/components/dropdown-menu.mdx

Installs the @kobalte/core package, which is a required dependency for the shadcn-solid Dropdown Menu component as it is built on top of Kobalte.

```bash
bun install @kobalte/core
```
