### Install Kobalte Core Dependency - npm

Source: https://github.com/hngngn/shadcn-solid/blob/main/docs/src/data/docs/components/number-field.mdx

Install the @kobalte/core package using npm. This package provides the underlying headless UI components used by the shadcn-solid NumberField.

```bash
bun install @kobalte/core
```
