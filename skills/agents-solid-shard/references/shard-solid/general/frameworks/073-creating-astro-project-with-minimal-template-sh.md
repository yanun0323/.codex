### Creating Astro Project with Minimal Template (sh)

Source: https://github.com/hngngn/shadcn-solid/blob/main/docs/README.md

This command initializes a new Astro project using the latest version and specifically applies the 'minimal' template. It's the standard way to quickly set up a new Astro project with a basic structure.

```sh
npm create astro@latest -- --template minimal
```
