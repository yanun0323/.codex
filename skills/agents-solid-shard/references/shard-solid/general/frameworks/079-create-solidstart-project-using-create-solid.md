### Create SolidStart Project using create-solid

Source: https://github.com/hngngn/shadcn-solid/blob/main/docs/src/data/docs/installation/solid-start.mdx

Initiate a new SolidStart project using the official create-solid CLI tool. This command sets up the basic project structure and dependencies, allowing selection of CSS frameworks like Tailwind or UnoCSS.

```bash
pnpm create solid@latest
```
