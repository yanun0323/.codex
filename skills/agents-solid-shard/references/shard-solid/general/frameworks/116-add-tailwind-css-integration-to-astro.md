### Add Tailwind CSS Integration to Astro

Source: https://github.com/hngngn/shadcn-solid/blob/main/docs/src/data/docs/installation/astro.mdx

Execute the Astro CLI command via pnpx to install and set up the official Tailwind CSS integration within the Astro project.

```bash
pnpx astro add tailwind
```
