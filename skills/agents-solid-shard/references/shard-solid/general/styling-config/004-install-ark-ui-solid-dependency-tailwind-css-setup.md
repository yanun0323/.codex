### Install ark-ui/solid Dependency (Tailwind CSS Setup)

Source: https://github.com/hngngn/shadcn-solid/blob/main/docs/src/data/docs/components/date-picker.mdx

Install the core dependency, @ark-ui/solid, which provides the underlying logic for the Date Picker component. This step is necessary when manually setting up the component with Tailwind CSS.

```bash
bun install @ark-ui/solid
```
