### Installing Kobalte Core Dependency (UnoCSS)

Source: https://github.com/hngngn/shadcn-solid/blob/main/docs/src/data/docs/components/context-menu.mdx

Install the core Kobalte library, which is a required dependency for the Context Menu component when using the UnoCSS setup.

```bash
bun install @kobalte/core
```
