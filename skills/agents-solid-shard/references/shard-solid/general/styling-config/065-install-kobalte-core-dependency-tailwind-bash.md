### Install Kobalte Core Dependency (Tailwind) - Bash

Source: https://github.com/hngngn/shadcn-solid/blob/main/docs/src/data/docs/components/button.mdx

Install the core Kobalte library, which is a required dependency for the button component when using Tailwind CSS.

```bash
bun install @kobalte/core
```
