### Install Kobalte Core Dependency (UnoCSS) - Bash

Source: https://github.com/hngngn/shadcn-solid/blob/main/docs/src/data/docs/components/button.mdx

Install the core Kobalte library, which is a required dependency for the button component when using UnoCSS.

```bash
bun install @kobalte/core
```
