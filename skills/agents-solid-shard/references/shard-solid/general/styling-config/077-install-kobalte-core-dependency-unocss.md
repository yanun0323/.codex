### Install Kobalte Core Dependency (UnoCSS)

Source: https://github.com/hngngn/shadcn-solid/blob/main/docs/src/data/docs/components/sheet.mdx

Install the core Kobalte library, which the shadcn-solid Sheet component depends on, specifically for UnoCSS integration.

```bash
bun install @kobalte/core
```
