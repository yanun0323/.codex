### Install Kobalte Core Dependency (TailwindCSS) (Bash)

Source: https://github.com/hngngn/shadcn-solid/blob/main/docs/src/data/docs/components/toast.mdx

Install the core Kobalte library, which provides the underlying logic for the Toast component. This is required for the component to function correctly when using TailwindCSS.

```bash
bun install @kobalte/core
```
