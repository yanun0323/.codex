### Install Kobalte Core Dependency (TailwindCSS Step) (Bash)

Source: https://github.com/hngngn/shadcn-solid/blob/main/docs/src/data/docs/components/radio-group.mdx

Installs the core Kobalte library, which is a required dependency for the Radio Group component when using Tailwind CSS.

```bash
bun install @kobalte/core
```
