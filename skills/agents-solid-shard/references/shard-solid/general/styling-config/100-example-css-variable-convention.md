### Example CSS Variable Convention

Source: https://github.com/hngngn/shadcn-solid/blob/main/docs/src/data/docs/theming.mdx

Shows how utility classes like bg-primary and text-primary-foreground map to corresponding CSS variables (--primary, --primary-foreground) following the defined naming convention.

```tsx
<div class="bg-primary text-primary-foreground">Hello</div>
```
