### Example CSS Variable Usage

Source: https://github.com/hngngn/shadcn-solid/blob/main/docs/src/data/docs/theming.mdx

Demonstrates applying background and text colors using utility classes that map to CSS variables (bg-background, text-foreground). This method is used when cssVariables is set to true.

```tsx
<div class="bg-background text-foreground" />
```
