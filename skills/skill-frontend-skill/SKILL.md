# Frontend Skill

Use when quality depends on art direction, hierarchy, imagery, restraint, and motion.

## Working Model

Before building, define:

- visual thesis: mood, material, energy
- content plan: hero/support/detail/final CTA or app workspace/navigation/context/actions
- interaction thesis: 2-3 meaningful motions

Each section gets one job, one dominant visual idea, and one takeaway/action.

## Defaults

- Start with composition, not components.
- Make the brand/product unmistakable in the first viewport.
- Prefer full-bleed hero/visual anchors for landing pages.
- Keep copy short; use whitespace, alignment, scale, crop, and contrast before chrome.
- Use at most two typefaces and usually one accent color.
- Default cardless: sections, columns, dividers, lists, and media blocks. Cards only when they are the interaction.
- Use strong real-looking imagery for brands, venues, editorial/lifestyle/product pages; imagery must carry narrative value and leave stable text areas.

## Landing Pages

Sequence: hero -> concrete support/proof -> detail/story/depth -> final CTA.

Hero rules: one composition, edge-to-edge when branded/full-bleed, brand first, narrow text column, strong contrast, tap targets, no cards/stat strips/logo clouds/pill soup/floating dashboards by default. Header + hero must fit common initial desktop/mobile viewports.

## Apps

Default to restrained product UI: calm hierarchy, dense but readable information, minimal chrome, one clear action/state accent. Start with the working surface, not a marketing hero. Headings should orient operation/status/action. Remove anything that does not help operate, monitor, or decide.

## Copy and Motion

- Product copy, not design commentary or prompt language.
- One sentence of support copy where possible; cut repetition.
- Use 2-3 intentional motions for visually led work: entrance, scroll/depth, hover/reveal/layout transition. Prefer Framer Motion when available. Motion must clarify hierarchy or atmosphere and stay smooth/restrained.

## Hard No

No default cards/hero cards/boxed hero, multi-accent noise, filler copy, split-screen hero without a unified calm side, generic SaaS card grids, repeated mood sections, or ornamental icons/gradients that do not improve scanning.

## Litmus

Brand visible? One strong visual anchor? Headline scan works? Each section one job? Cards necessary? Motion meaningful? Still premium without decorative shadows?
